# 🧮 Relatório de Análise Numérica - Métodos Numéricos em Python & LaTeX

Este repositório contém a implementação dos algoritmos de Análise Numérica referente ao **Semestre 2026.2** da **Universidade Estadual de Santa Cruz (UESC)**.

**Autor:** Evanderson Souza  
**Curso:** Ciência da Computação – UESC  
**Professor:** Prof. Gesil Sampaio Amarante II  

---

## 📌 Conteúdo do Repositório

- **Soluções de Equações Não Lineares:**
  - Bissecção
  - Posição Falsa (*Regula Falsi*)
  - Newton-Raphson
  - Secante
- **Solução de Sistemas Lineares:**
  - Eliminação de Gauss (com Pivoteamento Parcial)
  - Fatoração LU
  - Gauss-Jacobi
  - Gauss-Seidel

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.10+
- **Bibliotecas:** `NumPy`, `Pandas`

---

## 📂 Estrutura do Projeto

- `src/`: Códigos-fonte dos métodos em Python.
- `dados/entradas/`: Ficheiros `.txt` com os parâmetros de entrada dos exercícios do livro da Neide Franco.
- `dados/saida/`: Ficheiros `.csv` exportados com o histórico de iterações.
